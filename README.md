# Fast Food Simulator

This is a game made by Jonathan Sandström. The game is about working in a fast food restaurant, where the player will make food as fast as possible. 

This game is mostly inspired by Fast Food Simulator by No Ceiling Games on Steam. However, the organization has made a difficult choice not to provide feedback from players and continue finishing the game. As far as the Steam reviews go, new reviews of the game are now mostly mixed.

This is more of a personal project for me, as when I was playing their game, I found lots of issues, not just bugs, but mostly about balancing the game mechanics. Even though I wanted to see the changes from the developers, they won't want to sit around with the players and give feedback, as the developers were mostly concerned about how much code they needed to refactor. Soon enough, it was clear to me that they wouldn't fix the balance of the game anytime soon. That is when I decided to initialize this game.
